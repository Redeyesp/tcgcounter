Original board — micro-USB only.

Update over Wi-Fi (no cable, no BOOT button)

From v0.16 the board updates itself over Wi-Fi — a phone is enough:

  1. Download the app file for your board (on the phone or computer you will upload from): st7789-app.bin · ili9341-app.bin
  2. On the board: Home → tap the version button (top right) → START WI-FI.
  3. Join its Wi-Fi (scan the QR code on the screen), open http://192.168.4.1, choose the file and press Upload. It restarts into the new version by itself; saved games are kept.

If the page does not open on a phone, turn mobile data off for a moment.

Which one?

  • A mirrored or sideways picture with swapped colours means the other variant.
  • The serial log (115200 baud) prints a controller ID line at boot that names it.
  • Plug in with a USB data cable and pick the port (usually "USB-SERIAL CH340").

Erase or keep?

  • Leave “Erase device” unticked for updates: the saved game and the touch calibration are kept.
  • Tick it only for a clean start: the game resets and touch calibration runs again on the next boot.

If it doesn't connect

  1. No port listed → install the CH340 USB driver, or try another cable (many are charge-only).
  2. “Failed to connect” → hold BOOT, tap RST, release BOOT, then click install again.
  3. After flashing, tap RST if the board doesn't restart by itself.
  4. Close any serial monitor (Arduino IDE / PlatformIO) first — only one program can use the port.

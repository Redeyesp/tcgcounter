This browser can't flash devices. Use Chrome or Edge on a computer. Flashing needs HTTPS. Open this page from its github.io address.

Plug the board in with a USB data cable, click the button and pick the USB serial port (usually "USB-SERIAL CH340").

Erase or keep?

  • Leave “Erase device” unticked for updates: the saved game and the touch calibration are kept.
  • Tick it only for a clean start: the game resets and touch calibration runs again on the next boot.

If it doesn't connect

  1. No port listed → install the CH340 USB driver, or try another cable (many are charge-only).
  2. “Failed to connect” → hold BOOT, tap RST, release BOOT, then click install again.
  3. After flashing, tap RST if the board doesn't restart by itself.
  4. Close any serial monitor (Arduino IDE / PlatformIO) first — only one program can use the port.
